🚀 Project Title:
AI-Powered Space Station Object Detection System Using Synthetic Digital Twin Data

🎯 Project Objective:
To build a full-stack application that enables users (astronauts/engineers) to upload space station images, detect critical objects (toolbox, oxygen tank, fire extinguisher), and view detection results, performance metrics, and analytics using a seamless web interface backed by a YOLOv8-based Python backend with AI logic running in a Jupyter Notebook.

🧱 Tech Stack Overview
🔵 Frontend:
Framework: React.js or Next.js

Styling: Tailwind CSS + Framer Motion for animations

Features:

Upload interface for space images

Live visualization of detection results

Toggle dark/light/system themes

Admin dashboard to view logs, charts, mAP, confusion matrix

🟢 Backend:
Language: Python

Framework: FastAPI

Endpoints:

/upload: Accepts image and triggers model prediction

/results: Returns prediction data

/metrics: Returns evaluation metrics from Jupyter Notebook

/logs: Admin-only logs and analysis

🟠 AI Model (Jupyter Notebook):
YOLOv8 model (Ultralytics)

Dataset processing

Training, validation, mAP calculation

Confusion matrix, failure analysis

🔴 Database:
MongoDB (or PostgreSQL if needed)

Stores:

Upload metadata

Prediction results

Performance metrics

User logs

🧠 AI/ML Model Details
Model: YOLOv8 (multi-class object detection)

Framework: Ultralytics + PyTorch

Development Environment: Jupyter Notebook (for training, evaluation, experimentation)

Dataset:

Provided by Duality AI’s Falcon platform

Categories: Toolbox, Oxygen Tank, Fire Extinguisher

Already labeled in YOLO format

Includes train/val/test folders and config files

Metrics:

mAP@0.5

Confusion Matrix

Failure case analysis

🧪 How to Run the Project (Step-by-Step)
🔹 Dataset Setup
Create account on Falcon

Download dataset with YOLO labels

Place in dataset/ directory

🔹 Model Training (Jupyter Notebook)
Launch object_detection.ipynb in notebooks/

Train YOLOv8 model using Train set

Validate on Val set and export metrics

Save trained weights as yolov8_weights.pt
